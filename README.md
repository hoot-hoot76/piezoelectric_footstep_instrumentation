# Piezoelectric Footstep Energy Harvesting System

## 1. Project Overview

The Piezoelectric Footstep Energy Harvesting System is an Arduino-based project that demonstrates how mechanical pressure from footsteps can be converted into electrical energy using piezoelectric discs.

When pressure is applied to the discs, they generate an electrical signal through the piezoelectric effect. An Arduino Uno reads the generated signals, detects footsteps, estimates the voltage across a capacitor, and calculates the energy stored in it. A 16×2 I2C LCD displays the voltage, calculated energy, and total number of detected steps in real time.

The project demonstrates the principles of energy harvesting, analog signal measurement, embedded programming, and LCD interfacing.

## 2. Objectives

* Demonstrate the piezoelectric effect and its application in energy harvesting.
* Detect footsteps using electrical signals generated by piezoelectric discs.
* Measure voltage using the Arduino's analog input.
* Estimate stored electrical energy using a capacitor's voltage.
* Display voltage, calculated energy, and step count on an LCD.
* Monitor sensor readings and system output through the Serial Monitor.

## 3. Components Required

| Component                    | Purpose                                                                 |
| ---------------------------- | ----------------------------------------------------------------------- |
| Arduino Uno                  | Reads sensor signals, processes measurements, and controls the display. |
| Piezoelectric discs          | Generate electrical signals when mechanical pressure is applied.        |
| 16×2 I2C LCD                 | Displays voltage, calculated energy, and detected footsteps.            |
| Breadboard                   | Provides a platform for assembling the circuit without soldering.       |
| Jumper wires                 | Connect the electronic components.                                      |
| Capacitor (10 µF)            | Stores electrical charge for the energy measurement.                    |

| USB cable                    | Powers and programs the Arduino Uno.                                    |

*Additional rectification, protection, and energy-storage circuitry may be required depending on the piezoelectric input and the intended energy-harvesting design.*

## 4. Hardware Connections

### LCD 16×2 I2C

| LCD Pin | Arduino Uno |
| ------- | ----------- |
| VCC     | 5V          |
| GND     | GND         |
| SDA     | A4          |
| SCL     | A5          |

The LCD uses the I2C communication protocol, allowing it to communicate with the Arduino using two data lines.

### Analog Inputs

| Arduino Pin | Function                                                              |
| ----------- | --------------------------------------------------------------------- |
| A0          | Reads the voltage-divider output for voltage and energy calculations. |
| A1          | Reads the piezoelectric sensor signal for footstep detection.         |

The 100 kΩ and 10 kΩ resistors form the voltage divider used to scale the measured voltage to a level suitable for the Arduino's analog input.

**Important:** The piezoelectric input must be conditioned and protected against excessive voltage and negative transients before connection to the Arduino. The voltage-divider resistors alone do not provide complete input protection.

## 5. Software and Libraries

The project is developed using the Arduino framework with PlatformIO.

### Required libraries

* `Arduino.h` — provides Arduino functions such as `analogRead()`, `pinMode()`, and `millis()`.
* `Wire.h` — enables I2C communication.
* `LiquidCrystal_I2C.h` — controls the I2C LCD.

### Configuration

The LCD is initialized at I2C address `0x27` with 16 columns and 2 rows.

The analog reference voltage is set to 5.0 V, and the capacitor value used in the energy calculation is 10 µF.

## 6. How the Program Works

### Step 1: System Initialization

The Arduino initializes the LCD, activates its backlight, and displays startup messages. It then configures the analog input pins and starts serial communication at 9600 baud.

### Step 2: Voltage Measurement

The Arduino converts the analog reading from A0 into a voltage using the 5 V reference and the ADC's 10-bit resolution.

```cpp
dividerVoltage = rawValue * VREF / 1023.0;
```

The estimated capacitor voltage is then calculated using the voltage divider resistor values.

```cpp
capacitorVoltage = dividerVoltage * (R1 + R2) / R2;
```

### Step 3: Energy Calculation

The program estimates the energy stored in the capacitor using its capacitance and voltage.

```cpp
energy = 0.5 * capacitor * capacitorVoltage * capacitorVoltage;
```

The energy is converted from joules to millijoules for display.

```cpp
energy_mJ = energy * 1000.0;
```

Here, `capacitor` represents the capacitance in farads, `capacitorVoltage` is the estimated voltage across the capacitor in volts, `energy` is the calculated energy in joules, and `energy_mJ` is the energy in millijoules.

### Step 4: Footstep Detection

The Arduino continuously reads the analog signal from A1. When the reading rises above the threshold of 100 from a previous reading at or below that threshold, the program registers a step.

A delay of 500 milliseconds between registered steps prevents repeated counts caused by rapid signal fluctuations.

### Step 5: LCD Display

The LCD displays the calculated voltage and energy on the first row and the accumulated step count on the second row.

Example display:

```text
V:12.50 E:0.8
Steps: 5
```

*The values above are illustrative; actual readings depend on the circuit and test conditions.*

### Step 6: Serial Monitoring

The program sends the following information to the Serial Monitor at 9600 baud:

* Piezoelectric sensor reading from A1.
* Calculated voltage.
* Estimated energy in millijoules.
* Total detected footsteps.
* Raw analog reading from A0.

This information helps with observing sensor behaviour and troubleshooting the circuit.

## 7. Main Features

* Real-time voltage measurement.
* Capacitor energy estimation.
* Automatic footstep detection and counting.
* LCD-based data display.
* Serial output for debugging and monitoring.
* Adjustable footstep threshold and detection delay.

## 8. How to Run the Project

1. Assemble the circuit according to the connection tables.
2. Connect the Arduino Uno to the computer using a USB cable.
3. Open the project folder in Visual Studio Code with PlatformIO installed.
4. Ensure the required LCD library is included in `platformio.ini`.
5. Build and upload the program to the Arduino Uno.
6. Open the PlatformIO Serial Monitor and set the baud rate to 9600.
7. Apply pressure to the piezoelectric discs and observe the readings and step count.

## 9. Applications

Potential applications of piezoelectric energy harvesting include:

* Smart floor tiles in high-foot-traffic areas.
* Low-power wireless sensors.
* Foot-traffic monitoring systems.
* Vibration-powered monitoring devices.
* Educational demonstrations of renewable energy and embedded systems.

The amount of energy available from footsteps is limited, so practical applications depend on energy conversion efficiency, storage circuitry, cost, and power requirements.

## 10. Limitations

* Piezoelectric discs generally produce brief electrical pulses rather than a continuous power supply.
* Footstep detection depends on the threshold and quality of the input signal.
* Electrical noise and changing pressure can affect the readings.
* The voltage calculation assumes that the voltage-divider circuit is connected as intended.
* The energy value is an estimate based on the configured capacitance and measured voltage; it is not a direct measurement of the total energy harvested.
* The code does not measure current or calculate power.
* Reliable energy harvesting requires appropriate rectification, voltage protection, and energy-storage circuitry.

## 11. Future Improvements

Possible extensions include adding a rectifier and suitable energy-storage circuit, improving sensor filtering, recording measurements over time, and testing how different numbers of piezoelectric discs affect the output.

## 12. Conclusion

This project demonstrates how piezoelectric discs, an Arduino Uno, and an LCD can be combined to build a basic footstep energy-monitoring system. By measuring analog signals, estimating capacitor energy, and counting footsteps, the system provides a practical introduction to piezoelectricity, electronic circuit design, sensor interfacing, and embedded programming.
